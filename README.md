# ARK
Trading Platefrom

## Cross-platform desktop preview

Open `ARK.Portable.slnx` in Rider on macOS or Visual Studio on Windows with the .NET 10 SDK. Set `ARK.Desktop` as the startup project, or run:

```sh
dotnet run --project ARK.Desktop/ARK.Desktop.csproj
```

The preview opens a candlestick chart with generated sample data. Select a different symbol to redraw the chart. The remaining WPF windows and docking layout are still available in the Windows solution, `ARK.slnx`.
